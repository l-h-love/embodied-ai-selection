### 第 1 步：Ubuntu 22.04.5 真机双系统安装（P0，最高风险）

#### 1.1 安装前检查与备份

- [ ] 备份重要资料，至少保留一份到移动硬盘或云盘。
- [ ] 记录 BitLocker 恢复密钥；确认 Windows 的快速启动已关闭。
- [ ] 确认 BIOS 模式为 UEFI，记录 Secure Boot 状态。
- [ ] 确认硬盘布局，优先从 D 盘或独立硬盘留出不少于 120 GB 未分配空间。
- [ ] 用手机拍照：磁盘管理分区图、BIOS/UEFI 信息、BitLocker 状态。

#### 1.2 制作启动盘

- [ ] 下载 Ubuntu 22.04.5 LTS ISO。
- [ ] 校验 SHA256，并保存校验结果截图。
- [ ] 使用 Rufus 写入 16 GB 以上 U 盘，分区类型选 GPT、目标系统选 UEFI、文件系统 FAT32。
- [ ] 记录 ISO 文件名、U 盘容量、Rufus 参数和完成截图。

#### 1.3 安装 Ubuntu

- [ ] 从 U 盘启动，选择“Try Ubuntu”确认键鼠、网络、屏幕正常。
- [ ] 选择“其他选项/手动分区”，不要覆盖 Windows 分区。
- [ ] 复用已有 EFI 分区，不格式化。
- [ ] 分区建议：`/` 100 GB ext4；`swap` 16 GB；`/home` 使用剩余空间 ext4。
- [ ] 引导器安装到系统盘，确认启动项和磁盘编号后再执行。
- [ ] 安装完成后重启，确认 Windows 和 Ubuntu 都能进入。

#### 1.4 安装后验证

- [ ] 执行并截图：`lsb_release -a`、`uname -r`、`findmnt /`、`df -h`。
- [ ] 执行：`sudo os-prober && sudo update-grub`，确认 GRUB 同时识别 Windows 和 Ubuntu。
- [ ] 执行：`ubuntu-drivers devices`，安装推荐 NVIDIA 驱动。
- [ ] 重启后执行 `nvidia-smi` 并截图。
- [ ] 安装基础软件：Git、Python 3、pip、venv、build-essential、curl。
- [ ] 练习并记录：文件与权限、apt、进程、systemd、挂载 Windows D 盘、网络命令。

**完成标准：** 真机 Ubuntu 22.04.5 启动成功；`nvidia-smi` 正常；Windows 启动未损坏；全过程有截图和命令记录。

**如果安装失败：** 必须先写清失败步骤、报错原文、尝试过的方案和当前状态；不要写成“安装成功”。

#### 2.2 草图与特征学习

- [ ] 完成一个“完全定义”的草图：几何关系 + 智能尺寸，草图全部变黑。
- [ ] 练习特征：拉伸凸台、拉伸切除、旋转凸台、圆角、倒角、阵列、抽壳。

### 第 3 步：在 Ubuntu 上完成 YOLO 塑料瓶训练

> 最终训练环境必须是 Ubuntu 真机，并记录 `lsb_release -a`、`nvidia-smi`；不能把 WSL2 结果写成真机结果。

#### 3.1 准备环境与数据

- [ ] 在 Ubuntu 创建 Python 虚拟环境。
- [ ] 安装 PyTorch CUDA 版和 Ultralytics。
- [ ] 准备塑料瓶数据集：开源数据集或自采 150–300 张。
- [ ] 使用 LabelImg 或同类工具标注，统一为 YOLO txt 格式。
- [ ] 划分 train / val / test，写清数据来源、数量和标注规则。

#### 3.2 开始训练

- [ ] 编写 `plastic.yaml`，至少包含数据集路径、类别名称和划分文件。
- [ ] 先用 YOLO11n 小规模跑通，再开始正式训练。
- [ ] 推荐命令：
  `yolo detect train model=yolo11n.pt data=plastic.yaml epochs=100 imgsz=640 batch=16 device=0 workers=4 patience=20`
- [ ] 执行验证：
  `yolo detect val model=runs/detect/train/weights/best.pt data=plastic.yaml`
- [ ] 执行预测并保存图片或视频。
- [ ] 导出 ONNX：
  `yolo export model=runs/detect/train/weights/best.pt format=onnx opset=12`

#### 3.3 结果与复盘

- [ ] 保存 `results.png`、混淆矩阵、PR 曲线、验证指标和预测图。
- [ ] 解释 train/val loss 曲线，判断是否过拟合。
- [ ] 记录至少一次失败：OOM、标签错位、数据不均衡或显存不足。
- [ ] 可选加分：对比 YOLO11n 和 YOLO11s；分析 20 张误检/漏检图。

**完成标准：** Ubuntu 真机上训练成功；有曲线、指标、预测结果；失败过程也如实记录。

## 四、优先级结论

1. **先做 GitHub 初始化**：半天内就能补齐基础证据，并让后续过程自动留痕。
2. **再做 Ubuntu 真机安装**：这是最高风险、也最容易在面试追问中暴露真实性的任务。
3. **随后安装 SolidWorks 并完成 3 个模型**。
4. **最后在 Ubuntu 真机上完成 YOLO 塑料瓶训练与演示**。
5. **所有过程同步写学习记录、OKR，并提交 Git。**
