**失败预案（写进记录，不要慌）**：
- 进不去安装界面 → 关 Secure Boot 重试 / 换 U 盘接口（USB 2.0）/ Rufus 改 ISO 模式；

- 驱动装不上/黑屏 → 恢复模式 `nomodeset` 进系统，改回开源驱动后再试 570 版；
- **最坏情况**：保留 Windows 可用为前提，把 Ubuntu 装到外置 SSD（U 盘/移动硬盘）也算真机双系统，如实记录，不要用虚拟机顶替（任务明确"不要虚拟机"）。

## 5. 三大主线操作要点（浓缩版，执行时照着做）

### 5.1 Ubuntu 22.04.5 双系统（P0）

> **先校正起点**：本机已经安装 WSL2 `Ubuntu-24.04`（实测 24.04.3 LTS），并且实际用过 `apt`、`nano`、`systemctl`、Docker。你的 Linux 命令基础不是空白。
>
> **但 WSL2 ≠ 任务要求的真机双系统**：WSL 共用 Windows 内核，不经历 UEFI → GRUB → Linux 内核 → 驱动这条真机启动链，也不解决磁盘分区、引导修复、外设和 NVIDIA 驱动。再加上版本是 24.04，而选拔推荐 22.04.5。WSL 可以用来先练 Git/Python/YOLO 命令，但**不能作为任务 1 的完成证据**，面试时也不要把它说成双系统经历。

**为什么是 22.04.5**：选拔推荐版本 + LTS 稳定 + 对 30/40/50 系 N 卡驱动支持成熟（22.04.5 自带 6.8 HWE 内核，对新笔记本硬件兼容更好）。

**安装前 5 项检查（今天完成）**
1. `msinfo32` → BIOS 模式必须为 **UEFI**，确认安全启动状态；如果是 Legacy BIOS，先转 UEFI 或按机型教程处理；
2. 磁盘管理：确认 C/D 是否同一物理盘 → 决定压缩哪个分区（**统一建议：只压缩 D，不碰 C**）；
3. BitLocker：`manage-bde -status` 或设置里**挂起保护**（装完再恢复）；
4. 关闭 Windows「快速启动」（控制面板→电源选项→选择电源按钮功能→取消勾选）；
5. 备份：重要文件 + 浏览器书签 + 微信/QQ 数据；记下 Wi-Fi 密码。

**分区方案（安装器"其他选项"里手写）**

| 挂载点 | 大小 | 类型 | 说明 |
|---|---|---|---|
| EFI | **复用已有**（约 100–300MB 那个 FAT32） | — | **绝对不要格式化、不要新建**，否则 Windows 可能无法启动 |
| `/` | 100 GB | ext4 | 系统与软件 |
| `swap` | 16 GB | swap | 或跳过，用默认 swapfile |
| `/home` | 剩余全部（≥80GB） | ext4 | 你的数据 |

引导器安装位置：**选 Windows 所在的那块盘**（如 `/dev/nvme0n1`），不要选到单个分区。

**装完必做**
```bash
lsb_release -a                 # 确认 22.04.5
sudo apt update && sudo apt upgrade -y
sudo ubuntu-drivers devices    # 看推荐驱动
sudo ubuntu-drivers install    # 或"设置→附加驱动"选 570+ 专有驱动
sudo reboot
nvidia-smi                     # 必须能看到 RTX 5060 和驱动版本
sudo apt install build-essential git curl wget htop tmux -y
```

**常见坑（直接写进学习记录，面试也爱问）**
- 时间错乱（Windows 用本地时间、Linux 用 UTC）→ `timedatectl set-local-rtc 1 --adjust-system-clock` 或以管理员身份给 Windows 加 `RealTimeIsUniversal=1`；
- Wi-Fi/触摸板/亮度不可用 → 换 22.04.5（HWE 内核）或在"附加驱动"里装固件；
- GRUB 里没有 Windows → `sudo apt install os-prober && sudo os-prober && sudo update-grub`；
- **不要**在 Ubuntu 里动 Windows 分区，也不要用第三方工具做"一键修复引导"。

### 5.3 SolidWorks 建模顺序（只学这两块，别贪）

1. **界面与操作**：视图旋转（中键）、平移（Ctrl+中键）、缩放（滚轮）、前视/上视/右视基准面；
2. **草图板块**：选基准面 → 画轮廓 → 加几何关系（水平/垂直/相切/同心/对称）→ 智能尺寸 → 直到**完全定义**（草图全部变黑，左下角显示"完全定义"）；
3. **特征板块**：拉伸凸台/基体（给定深度/成形到一面）、拉伸切除、旋转凸台、圆角、倒角、阵列（线性/圆周）、抽壳、参考几何体（基准面/轴）；
4. **三个必做练习**（顺序即难度）：
   - L 形支架：矩形草图 → 拉伸 → 切除孔 → 线性阵列 → 圆角；
   - 塑料瓶（回转体）：画半剖面草图 + 中心线 → 旋转 → 抽壳 → 圆角/螺纹装饰；
   - 机器狗舵机支架：多基准面 + 切除 + 阵列（**面试时这张图最能体现"和具身智能相关"**）。
5. 每个模型交付：过程截图 3–5 张 + 完成图 + 工程图 PDF + 3 行文字说明（关键尺寸/草图是否完全定义/踩的坑）。

### 5.4 YOLO 塑料瓶训练（P1，你的强项，重点在"Ubuntu 上重跑 + 留痕"）

> 可以先在 WSL2 中整理数据、验证命令和做小样本检查；最终训练优先放到真机 Ubuntu 22.04.5 + RTX 5060 上，并在记录中写清 `lsb_release -a`、`nvidia-smi` 和实际设备。若确实在 WSL 中运行，也必须如实标注 WSL，不能与任务 1 混为一谈。

- 数据集来源（三选一，按可行性）：Roboflow Universe 塑料瓶数据集（最快，选 YOLOv8 格式导出）；Kaggle/开源垃圾数据集（如 TrashNet、TACO）过滤出 bottle 类；自采 150–300 张 + `labelImg` 标注（**最能体现动手能力，也最适合讲"数据质量比模型更重要"**）。
- 标签规范：1 类 `plastic_bottle`（或 2 类：`bottle` + `cap`），YOLO txt 格式 `class cx cy w h`（归一化）；
- 训练命令（8GB 显存版）：
  ```bash
  yolo detect train model=yolo11n.pt data=plastic.yaml epochs=100 imgsz=640 batch=16 device=0 workers=4 patience=20
  yolo detect val model=runs/detect/train/weights/best.pt data=plastic.yaml
  yolo detect predict model=runs/detect/train/weights/best.pt source=demo.mp4 save=True
  yolo export model=runs/detect/train/weights/best.pt format=onnx opset=12
  ```
- 训练记录必写 4 项：数据规模与来源、超参、**曲线解读**（train/val loss 何时分离＝过拟合信号）、失败尝试（OOM、标签错位、类别不均衡）；
- 加分衔接：把竞赛里的做法搬过来——错误样本归因（画 20 张错检/漏检图并分类）→ 针对性补数据 → 重训对比。这一段面试讲出来，水平立刻区别于"跑了个官方 demo"的人。
